# DermatoBlood AI

DermatoBlood AI is a FastAPI-based research prototype that analyzes uploaded fingerprint images with OpenCV SIFT preprocessing and a PyTorch CNN. It provides a browser UI, prediction metadata, scan history, visual processing outputs, and downloadable PDF reports.

> **Important medical disclaimer:** This project is for research, demonstration, and educational use only. It is **not** a clinically validated diagnostic device and must not be used to determine a person's blood group or make medical decisions. Always confirm blood group through an approved laboratory test and qualified medical professional.

## Features

- Fingerprint image upload through a web interface
- Image enhancement, adaptive binarization, ridge-density calculation, and SIFT keypoint visualization
- PyTorch model with separate ABO and Rh prediction heads
- SQLite-backed scan history
- Downloadable clinical-style PDF reports
- Automatic model training when model weights are missing
- JSON API endpoints for prediction, history, metrics, and reports

## Requirements

- Python 3.10 or newer
- `pip`
- CPU is sufficient; CUDA is optional for model training

## Installation

Create and activate a virtual environment, then install the dependencies:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run locally

From the project root:

```powershell
python run.py
```

Open <http://localhost:8000> in a browser. The application opens the URL automatically on most systems.

If `models/blood_group_model.pth` is absent, the application trains and saves a local model before starting. Training data is procedurally generated by `scripts/generate_data_and_train.py`; it is not a clinically validated blood-group dataset.

## API endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| `GET` | `/` | Web application |
| `GET` | `/api/generate-patient-id` | Generate a demo patient ID |
| `POST` | `/api/predict` | Process a fingerprint image and return a prediction |
| `GET` | `/api/history` | Return recent local scan history |
| `GET` | `/api/metrics` | Return prototype evaluation metrics |
| `GET` | `/api/download-report/{scan_id}` | Generate and download a PDF report |

Interactive API documentation is available at <http://localhost:8000/docs> while the server is running.

## Data and privacy

The local SQLite database stores patient fields and base64-encoded image visualizations. It is intentionally ignored by Git and should never be committed if it contains real personal or biometric data. The `reports/` directory is also ignored except for its placeholder file.

Before using this project with any real data, add authentication, access controls, encryption, retention rules, audit logging, and a formal privacy/compliance review.

## GitHub publishing checklist

1. Create a new **empty** GitHub repository (do not add a README or `.gitignore` there).
2. Copy its HTTPS URL, for example `https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git`.
3. In this project folder, run:

   ```powershell
   git init
   git add .
   git commit -m "Initial commit: DermatoBlood AI"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   git push -u origin main
   ```

4. When GitHub asks for authentication, use your GitHub sign-in flow or a Personal Access Token instead of an account password.

Do not commit `blood_group_app_v2.db`, generated PDF reports, real fingerprint images, patient data, or any credentials.
